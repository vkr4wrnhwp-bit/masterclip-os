# Street Banker Song Lab — complete feature map

Owner revision: 2026-10-23. Suite name **Song Lab**, monogram **SL**; public name **Street Banker Song Lab**. Nothing is removed from the current preview. The six steps group controls into named panels rather than hiding them. Every destination below has a self-contained HTML mockup. Stage features live in Stage, with the same suite sign-in.

## Status and display truth

Today’s status assesses existing source, not the proposed redesign or a live account. Real means a source-traced engine/record operation; hosted providers need their keys; built-in/synthetic fallback data stays Sample; pending counterpart work is Stub. The new shell and verified cross-service connections remain Not built. **All artwork, waveforms, meters, values and records in every mockup are Sample / Example, even when the underlying existing feature is Real.** Conditions remain in INVENTORY.md. No row grants A&R/approval permissions.
